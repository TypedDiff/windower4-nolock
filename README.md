## About

InstantAH is an addon for [Windower 4](http://www.windower.net), which enables instant feedback for bids when using the auction house

The same functionality can be found in the [InstantAH](https://git.ashitaxi.com/Addons/instantah/src/branch/master/instantah.lua) for [Ashita v3](https://www.ashitaxi.com):

## Setup

- 1) Copy the instantah folder into your Windower addons folder.
